# Kontrybucje

[🇬🇧 English version below](#contributing)

Dzięki, że chcesz pomóc przy RozliczKorki! Zanim otworzysz pull request, przeczytaj
poniższe zasady.

## Jak zgłosić zmianę

1. Zrób fork repozytorium i utwórz gałąź od `main`.
2. Przed wypchnięciem uruchom te same sprawdzenia co CI:

   ```sh
   pnpm format:fix
   pnpm lint:typecheck
   pnpm lint:check
   pnpm format:check
   ```

3. Otwórz pull request z krótkim opisem zmiany i potwierdź zgodę na warunki licencyjne
   z sekcji poniżej.

# Contributing

Thanks for wanting to help with RozliczKorki! Please read the guidelines below before
opening a pull request.

## How to submit a change

1. Fork the repository and create a branch from `main`.
2. Before pushing, run the same checks as CI:

   ```sh
   pnpm format:fix
   pnpm lint:typecheck
   pnpm lint:check
   pnpm format:check
   ```

3. Open a pull request with a short description of the change and confirm that you
   agree to the license terms in the section below.
